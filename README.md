# مغامرات حاتم وورد — النسخة الأولى

لعبة قصصية تفاعلية للأطفال (3–4 سنوات). يختار الطفل أن يكون **حاتم** أو **ورد**، ويساعدان الديناصور الصغير «دودو» على الوصول لأمه، عبر ثلاثة مواقف عن التعبير عن المشاعر والمشاركة والتعاون.

- تعمل على الآيباد والجوال، وبالعربية من اليمين لليسار.
- لا تحتاج تسجيل دخول ولا إنترنت ولا قاعدة بيانات.
- لا تجمع أي بيانات ولا تعرض إعلانات. يُحفظ التقدم على الجهاز نفسه فقط.

---

## التشغيل

**الطريقة الأسهل:** افتحي `index.html` في المتصفح مباشرة.

**على الآيباد دون إنترنت:**
1. انسخي المجلد كاملًا إلى تطبيق «الملفات».
2. افتحي `index.html`.

**ملاحظة عن الخط:** خط العناوين (Baloo Bhaijaan 2) يُحمَّل من الإنترنت إن توفر. دون إنترنت يُستخدم خط الجهاز العربي، وتعمل اللعبة بشكل كامل.

---

## بنية الملفات

```
index.html              الهيكل فقط (الشاشات والأزرار)
styles.css              التصميم والحركات والتجاوب
js/story.js             القصة كاملة: المشاهد والجمل والاختيارات (بيانات فقط)
js/game.js              المحرك: التنقل والحوار والاختيارات والنجوم والحفظ
js/characters.js        عرض الشخصيات (صورتك إن وُجدت، وإلا الرسم المؤقت)
js/backgrounds.js       عرض الخلفيات (صورتك إن وُجدت، وإلا الرسم المؤقت)
js/audio.js             مدير الصوت والمؤثرات
assets/assets.js        سجل الصور: هنا تُكتب مسارات صورك
assets/audio/manifest.js سجل الأصوات: هنا تُكتب مسارات التسجيلات
assets/characters/      صور الشخصيات
assets/backgrounds/     صور الخلفيات
assets/audio/lines/     تسجيلات الحوار
assets/audio/effects/   المؤثرات الصوتية (اختياري)
assets/effects/         أيقونات الاختيارات (اختياري)
ASSETS.md               مواصفات كل صورة وصوت مطلوب
```

**لماذا الإعدادات ملفات `.js` وليست `.json`؟** المتصفح يمنع قراءة ملفات JSON عند فتح الصفحة مباشرة من الجهاز دون خادم. بصيغة JS تعمل اللعبة من أي مجلد.

## إضافة الصور

1. ضعي الصورة في مجلدها، مثال: `assets/characters/hatem/happy.png`.
2. في `assets/assets.js` غيّري السطر المناسب:
   ```js
   hatem: { base: "...", happy: "assets/characters/hatem/happy.png", sad: null, ... }
   ```

**حاتم وورد** لكل منهما صورة جسم كاملة لكل تعبير: ضحك، احتفال، حزن، زعل، استغراب، خوف، بكاء، وتفكير (يظهر وقت الاختيار). جدول الحالة في `ASSETS.md`. أي تعبير ليس له صورة يُعرض بالصورة العادية `base`، مع «فقاعة شعور» فوق الرأس إن وُجد لها وجه في `feelings`.
3. أعيدي تحميل الصفحة.

المواصفات الكاملة (المقاسات والشفافية ووضع القدمين) موجودة في `ASSETS.md`.

## استوديو التسجيل (داخل اللعبة)

1. في شاشة البداية اضغطي **مطوّلًا** على زر الميكروفون 🎙️ أعلى الشاشة. الضغطة القصيرة لا تفتحه، حتى لا يفتحه الأطفال صدفة.
2. اختاري المتكلم من الأعلى: الراوية، أو حاتم، أو ورد، أو دودو، أو ماما دودو.
3. لكل جملة:
   - **سجّلي:** يبدأ التسجيل. اضغطي **إيقاف** بعد انتهاء الجملة، فيُعاد لك تلقائيًا لتسمعيه.
   - **استمعي:** يشغّل التسجيل المحفوظ.
   - **أعيدي:** يسجّل الجملة من جديد مكان القديم.
   - **حذف:** يحذف التسجيل، ويحتاج ضغطتين للتأكيد.
4. التسجيلات تعمل في اللعبة فورًا، ولا تحتاج أي خطوة إضافية.

**مهم:**
- التسجيلات محفوظة **على هذا الجهاز وهذا المتصفح فقط**.
- **⬇ تصدير التسجيلات** يجهّز ملف zip فيه كل التسجيلات. احتفظي به نسخة احتياطية، أو أرسليه لي لأضيف التسجيلات للعبة بشكل دائم فتعمل على كل الأجهزة.
- **استيراد ملف** يرجّع التسجيلات من ملف صدّرتِه، على نفس الجهاز أو على جهاز آخر.
- Safari قد يمسح بيانات المواقع التي لا تُفتح لفترة طويلة. صدّري التسجيلات بعد كل جلسة، أو أضيفي اللعبة إلى الشاشة الرئيسية عبر زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».
- الميكروفون يعمل فقط من موقع اللعبة على GitHub Pages، ولا يعمل من رابط Claude ولا من ملف مفتوح من الجهاز.

## إضافة تسجيلات العائلة (يدويًا)

1. سجّلي الجملة. يكفي تطبيق «مذكرات صوتية» في الآيفون، ويحفظ بصيغة m4a.
2. سمّي الملف باسم معرّف الجملة، مثال: `s1_02.m4a`، وضعيه في `assets/audio/lines/`.
3. في `assets/audio/manifest.js` ابحثي عن المعرّف، وبجانبه نص الجملة واسم المتكلم، وغيّري `null` إلى المسار:
   ```js
   "s1_02": "assets/audio/lines/s1_02.m4a",   // ورد: أنا أنزل أول! أنا الأكبر!
   ```

لا تحتاجين تعديل القصة ولا المحرك. يمكنك إضافة التسجيلات تدريجيًا، وأي جملة بلا تسجيل يظهر نصها فقط.

---

## إضافة موقف جديد أو تعديل نص

كل النصوص في `js/story.js`، وأعلى الملف شرح لكل حقل.

- **تعديل جملة:** غيّري `text`. إن كان لها تسجيل، أعيدي تسجيلها.
- **موقف جديد:** انسخي كتلة `s2` بمشاهدها (`s2_good_*` و`s2_hint_*`)، وغيّري المعرّفات، ثم اربطيها بحقل `next` في المشهد الذي قبلها.
- **بعد أي تعديل:** أضيفي معرّفات الجمل الجديدة إلى `manifest.js`. إن نسيتِ، تعمل الجملة بلا صوت ولا تتعطل اللعبة.

## كيف تعمل اللعبة

```
شاشة البداية → اختيار الشخصية → الافتتاحية
  → الموقف 1 (الزحليقة) → الموقف 2 (الحجر اللامع) → الموقف 3 (جسر النهر)
  → النهاية المشتركة → «نجمة الصديق المتعاون»
```

**كل موقف:**
- ثلاثة اختيارات للشخصية المختارة، **مرتبة عشوائيًا** في كل مرة حتى لا يحفظ الطفل المكان بدل المعنى.
- الاختيار المناسب يعطي نجمة، ثم ينتقل الطفل للموقف التالي.
- الاختيار غير المناسب يعرض كيف شعرت الشخصية الأخرى، مع تلميح لطيف، ثم زر «نجرّب مرة ثانية». لا خسارة ولا عقاب.

**الأزرار العلوية:**
- 🏠 إعادة المغامرة، وتسأل قبل التنفيذ.
- ↻ إعادة المشهد.
- 🔊 كتم الصوت.

**أزرار الحوار:**
- 🔊 إعادة الجملة.
- ◀ التالي.

**الحفظ:** يُحفظ التقدم تلقائيًا. عند فتح اللعبة مرة أخرى يظهر زر «أكمل المغامرة».

## قائمة فحص على الآيباد الحقيقي

هذه أمور لا يمكن التحقق منها إلا على الجهاز نفسه:

- [ ] بعد ضغط «ابدأ» تُسمع المؤثرات، وتأكدي أن زر الصامت الجانبي في الآيباد غير مفعّل.
- [ ] بعد إضافة أول تسجيل: يُسمع، والشخصية تتحرك أثناء الكلام.
- [ ] الحركة سلسة دون تقطيع.
- [ ] الأزرار مريحة لأصابع حاتم وورد، ولا يحدث تكبير للصفحة عند النقر المزدوج.
- [ ] تدوير الآيباد أثناء اللعب يعيد ترتيب الشخصيات.
- [ ] قفل الشاشة ثم فتحها لا يوقف اللعبة.
- [ ] إغلاق Safari ثم فتحه يُظهر زر «أكمل المغامرة».
